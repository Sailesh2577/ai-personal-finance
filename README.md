# AI Personal Finance Dashboard

This is a personal finance dashboard application built with Next.js, React, and Tailwind CSS. It provides a user-friendly interface to track your portfolio and manage your expenses.

## Features

*   **Portfolio Summary:** View a summary of your investment portfolio, including total value, gains/losses, and daily changes. A historical chart visualizes your portfolio's performance over time.
*   **Expense Tracker:** Keep a detailed record of your expenses. You can add new expenses, categorize them, and view a list of all your transactions.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

*   Node.js (v20 or later)
*   npm

### Installing

1.  Clone the repository:

    ```bash
    git clone https://github.com/your-username/ai-personal-finance.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd ai-personal-finance
    ```

3.  Install the dependencies:

    ```bash
    npm install
    ```

### Running the Application

To run the application in development mode, use the following command:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
